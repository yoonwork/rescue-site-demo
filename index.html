방문자가 몰려도 안 다운되는 구조

홈페이지를 미리 인쇄해 전국 여러 지점에 나눠 두는 방식이에요. 방문자는 가까운 지점에서 받아 가니까 한 곳에 줄이 서지 않아요.

① 운영진이 글·사진 올림쉬운 관리자에서 저장. 글은 DB(Supabase), 사진은 Cloudflare R2에
② 사진 자동 최적화올릴 때 큰 사진·썸네일로 줄여 저장. 휴대폰 사진 그대로 올려도 돼요
③ 홈페이지를 다시 만들어 배포저장을 모아서 보통 5분 안팎에 반영. 무료 빌드 한도(월 500회) 안에서 운영
④ 방문자는 CDN에서 받음페이지와 사진은 Cloudflare CDN이 보내요. 서버가 바빠지지 않아요
  • 트래픽: 페이지와 사진은 Cloudflare CDN의 정적 파일로 나가서 전송량·요청 수 한도가 없어요. 서버 코드가 도는 곳은 신청 폼 접수와 옛 주소 이동뿐이라 하루 10만 건 무료 한도에 비해 여유가 커요.
  • 사진 비용: 사진은 전송료가 없는 Cloudflare R2에 둬서, 구조 영상이 퍼져도 사진 전송 요금이 늘지 않아요.
  • 비공개 글: 숨김·임시저장 글은 공개 화면에 만들어지지 않고 DB 권한으로도 막아요. 예전 배포 주소와 미리보기 주소는 운영진만 열 수 있게 잠가요.
  • 장애 복구: 화면은 배포할 때마다 이전 버전이 남아 버튼 하나로 되돌려요. DB 자동 백업은 Supabase 유료 요금제(월 25달러~)에서 매일 돼요.
  • 옛 주소: 카페24의 '?no=123' 같은 옛 주소는 작은 Cloudflare 프로그램이 대응표를 보고 새 주소로 영구 이동(301)시켜요.
  • 플랫폼 종속 탈피: 소스는 단체 소유 저장소에, 데이터는 표준 DB(PostgreSQL)에 둬서 언제든 다른 곳으로 옮길 수 있어요.
