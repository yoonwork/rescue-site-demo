구조

제보를 받으면 현장을 확인하고, 위급한 동물은 바로 데려와 응급 치료를 받게 해요.

치료·보호

입양·사후 관리

전화 상담과 만남으로 잘 맞는 가족을 찾고, 입양 뒤 한 달·석 달에 안부를 여쭤요.

트래픽
페이지와 사진은 Cloudflare CDN의 정적 파일로 나가서 전송량·요청 수 한도가 없어요. 서버 코드는 신청 폼 접수와 옛 주소 이동에만 돌아요(하루 무료 10만 건).
사진 비용
사진은 전송료가 없는 Cloudflare R2에 둬서, 구조 영상이 퍼져도 사진 전송료는 0원이에요. 목록에는 썸네일만, 화면에 보일 때만 불러와요.
비공개 글
숨김·임시저장 글은 공개 화면에 만들어지지 않고 DB 권한으로도 막아요. 예전 배포 주소와 미리보기 주소는 운영진만 열 수 있게 잠가요.
장애 복구
화면은 배포할 때마다 이전 버전이 남아 버튼 하나로 되돌려요. DB 자동 백업은 Supabase 유료 요금제(월 25달러~)에서 매일 돼요.
옛 주소
카페24의 ‘?no=123’ 같은 옛 주소는 작은 Cloudflare 프로그램이 대응표를 보고 새 주소로 영구 이동(301)시켜요.
플랫폼 종속 탈피
소스는 단체 소유 저장소에, 데이터는 표준 DB(PostgreSQL)에 둬서 언제든 다른 곳으로 옮길 수 있어요.
